# images

Drop image files here, then point at them from the HTML.

- **Portrait** — add your photo (e.g. `portrait.jpg`) and change the `src` in
  `index.html` from `images/portrait.svg` to `images/portrait.jpg`.
- **Project thumbnails** — add one image per project (e.g. `sparse-one.jpg`)
  and change that project's `src` from `images/placeholder.svg`.

`placeholder.svg` and `portrait.svg` are just gray stand-ins so the layout
looks right before you have real images. Delete them once they're unused.

Thumbnails are displayed at 120×90 px, so anything roughly 4:3 and at least
240×180 px will look fine.
